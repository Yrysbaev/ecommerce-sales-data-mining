# E-commerce Sales Data Mining Project

This repository contains our group project for analyzing E-commerce sales data using data mining techniques.  

## 📊 Project Overview

We explore customer purchasing behavior, product performance, and sales trends using:  
- **Classification**: Categorizing customers by spending habits  
- **Clustering**: Grouping similar shoppers  
- **Association Rules**: Discovering frequently bought-together products  

Our goal is to provide insights for businesses to improve sales strategies, customer retention, and personalized marketing.

## 🗂 Repository Structure

```
/data           → Raw dataset files (e.g., CSV)

/presentation   → PowerPoint presentation slides
  
/report         → Final written report or summary
  
requirements.txt → Python dependencies list
```

---

## 💻 How to Run

1. Clone this repository:
   ```
   git clone https://github.com/yourusername/ecommerce-sales-data-mining.git
   ```
2. Navigate into the folder:
   ```
   cd ecommerce-sales-data-mining
   ```
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

4. Open and run the Jupyter Notebook:
   ```
   jupyter notebook notebooks/analysis.ipynb
   ```
